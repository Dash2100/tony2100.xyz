報名的時候我以為這只是一場比賽，結束之後才發現，它把我整個暑假都吃掉了。但如果你問我值不值得，我會說：撇除不好玩的部分，其實都蠻好玩的。

## 賽前準備

準備期大概三個月，我把時間切成三塊：基礎、實戰、心態。

### 基礎不能省

很多人一開始就想做出很炫的東西，結果連 flexbox 的對齊都要 Google。我的建議是先把這些刻進肌肉記憶：

- 語意化的 HTML 結構
- Flexbox 與 Grid 的排版直覺
- RWD 的斷點思維
- 基本的 JavaScript DOM 操作

### 實戰才是王道

我每天會限時做一份完整的版型，從設計稿到切版控制在三小時內。一開始當然做不完，但兩週後速度就上來了。

> 在成功路上，一定有紅綠燈。重點不是不停下來，而是停下來的時候你在想什麼。

## 比賽當天

當天最大的敵人不是題目，是緊張。我準備了一份自己的 reset CSS，開場直接貼上，省下不少時間：

```css
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

img {
  display: block;
  max-width: 100%;
}
```

時間分配大概是這樣：

1. 前 15 分鐘讀題、拆元件
2. 中間 4 小時切版與功能
3. 最後 30 分鐘檢查 RWD 與跑版

## 我學到的事

技術會過時，但解決問題的方法不會。比賽教我的不是某個框架，而是怎麼在壓力下保持冷靜、怎麼把大問題拆成小問題。

如果你也想參加，我只有一句話送你：去做就對了。
